# Showdown Poker

Тренажёр шоудауна в техасском холдеме. Откройте сайт и сразу начинайте тренировку, установка не нужна.

ЛКМ или касание — следующая группа. ПКМ или кнопка «Равная рука» — добавить игрока к последней группе.

Расчёт рук: pokersolver 2.1.4 (MIT), https://github.com/goldfire/pokersolver . Обязательная лицензия сохранена в pokersolver-LICENSE.md. Все зависимости локальные; серверная обработка и CDN не используются.
